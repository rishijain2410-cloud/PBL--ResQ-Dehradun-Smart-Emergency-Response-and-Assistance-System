Smart Emergency Response and Assistance System

ResQ Dehradun is a proposed emergency assistance system designed to help people access essential emergency services in Dehradun.
The project aims to bring emergency assistance, healthcare discovery, and navigation-related services together in one platform.

🎯 Project Objectives
Improve access to emergency assistance.
Help users discover hospitals and healthcare services.
Provide hospital information, including departments, doctors, and bed availability.
Support navigation to relevant emergency facilities.
Integrate multiple modules into a unified system.
🏗️ Project Modules
Module	Description
M1 – Emergency & SOS	Emergency assistance and SOS functionality
M2 – Healthcare	Hospital discovery, departments, doctors, medical services, and bed availability
M3 – Navigation & Transport	Navigation and transport-related functionality
M4 – Frontend & Integration	User interface and integration of project modules
